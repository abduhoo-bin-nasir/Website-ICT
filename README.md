# Burger Website Project 🍔

This repository contains a **multi-page Burger Website** developed as a **university group project**.  
The project demonstrates the application of foundational **web development concepts** using structured HTML and CSS, along with effective team collaboration through GitHub.

---

## 📄 Website Pages

The website consists of the following pages:

- **Home** – Provides an introduction and overview of the website  
- **Menu** – Displays the available burger items and offerings  
- **About Us** – Describes the concept and purpose of the website  
- **Members** – Presents the project team along with links to individual portfolios
